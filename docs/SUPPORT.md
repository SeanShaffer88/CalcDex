# Support

- **Built-in help first.** The window's HELP panel (F1) and
  `CalcDex --help` / `CalcDex --help-guide` on the command
  line cover everyday use, and
  [TROUBLESHOOTING.md](TROUBLESHOOTING.md) covers the common
  problems. Both work fully offline.
- **Questions and bug reports** go to the project's GitHub
  Issues: <https://github.com/SeanShaffer88/CalcDex/issues>.
  CalcDex sends no telemetry, so a useful report needs what
  you saw, what you expected, the exact inputs, and your
  version (`CalcDex --version`). A failing calculation is
  easiest to reproduce from its command-line form, e.g.
  `CalcDex bmi 70 175`.
- **Security problems** are handled differently — see
  [SECURITY.md](SECURITY.md).

CalcDex is free software maintained in the open; see
[MAINTAINERS.md](MAINTAINERS.md) and
[GOVERNANCE.md](GOVERNANCE.md) for who looks after it.
