# Code of Conduct

Everyone taking part in this project — issues, pull
requests, discussions — is expected to:

- Be respectful and constructive; criticise ideas and code,
  not people.
- Keep discussion on the project: calculators, correctness,
  clarity and craft.
- Accept the maintainer's decisions on scope and releases
  (see [GOVERNANCE.md](GOVERNANCE.md)).

Harassment, personal attacks and spam are not welcome. The
maintainer may remove content and, if it continues, block
participation. Report problems through GitHub Issues or,
for anything sensitive, the route in
[SECURITY.md](SECURITY.md).
