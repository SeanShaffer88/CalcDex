# Features

CalcDex is one offline program holding **316 calculators**.
Everything listed here works in the window **and** on the
command line — the window and the CLI dispatch through the same
registry (see [PARITY.md](PARITY.md) for the capability matrix).

## The calculators

- **Everyday & money** — loan and mortgage payments, compound
  interest, savings goals, tips, discounts, tax, currency-style
  ratio work, percentages of every kind.
- **Maths & statistics** — arithmetic, fractions, powers and
  roots, mean/median/mode, standard deviation, percentiles,
  probability, combinatorics, number sequences.
- **Science** — physics (motion, energy, electricity, waves,
  optics), chemistry (moles, dilutions, titration helpers), a
  free Expression Calculator with CODATA 2018 constants,
  user-defined constants, typed quantities (`154 lb`,
  `5 ft 9 in`) and uncertainty propagation (`10 ± 0.2`).
- **Health** — BMI, BMR/TDEE, body composition and related
  everyday health figures.
- **Dates & time** — age, date differences, working days,
  countdowns.
- **Engineering (v0.8.0)** — electronics (Ohm's law, resistor
  colour codes, voltage dividers), materials data (density,
  resistivity, Young's modulus for common materials), stress
  and unit conversions.

## Around the calculators

- **Calculation log.** Every successful run — window or
  command line — is saved to a searchable, filterable log
  (500 entries, pinned entries exempt) with tags and notes,
  backup-before-edit, clear-with-undo, and plain-text and
  lab-record exports.
- **Favourites, recent and remembered inputs**, stored in the
  shared settings file, plus display formats (significant
  figures, decimals, engineering, exact fractions), rounding
  modes, PASS/FAIL spec checks and copy formats (plain,
  LaTeX, scientific, CSV).
- **For students** — worked steps (standard or deeper),
  answer checking, seeded practice problems, plots as CSV,
  worked-solution export.
- **For teachers** — problem sets with answer keys and
  worksheets, CSV marking, formula sheets, course packs
  (GCSE, A-Level, AP, Undergrad), saved class examples, a
  demonstration mode that hides result values, and a
  classroom projection mode (larger, higher contrast).
- **Batch runs.** One calculator over a whole CSV file, with
  overwrite protection and backup.
- **Built-in help** in the window (F1) and on the command
  line (`--help`, `--help-guide`) — no internet needed.
- **Offline by design.** The only network feature is an
  offer-only update check (off by default; it reads the
  latest release number and downloads nothing).
