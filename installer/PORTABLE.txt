CalcDex — portable build

Just run CalcDex.exe. Nothing is installed. No internet is used
unless you press Check for updates in the HELP panel (or switch on
the startup update check there — it is off by default).
Delete the folder to remove it completely. Everything the program
writes — settings, the calculation log (every successful calculation,
saved automatically) and saved class examples — lives in the data
folder beside CalcDex.exe, and nowhere else. (Files from versions
before 0.9.0, kept in %APPDATA%\CalcDex, are copied across on first
run and the originals left untouched.) View the log with the LOG
button, or with CalcDex.exe --log; empty it with
CalcDex.exe --clear-log. CalcDex.exe --clean removes all of the
program's files from the data folder.

Every calculator also works from the command line, for example:
  CalcDex.exe --list
  CalcDex.exe compound-interest 1000 5 10
  CalcDex.exe bmi 70 175
  CalcDex.exe age 04/23/1988 10/25/2026
  CalcDex.exe --log

Windows may warn on first run; choose More info, then Run anyway, if you
trust this build. You can check the file's SHA-256 against the release
notes where you downloaded it.
